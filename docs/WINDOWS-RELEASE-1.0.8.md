Windows 1.0.8 修复官方客户端更新后动画停在加载失败、任务栏理世图标没有绑定的问题。

原因：客户端自动更新至 26.1016.8622.0，而隐藏窗口恢复只允许旧版 26.1013.4894.0；启动器缓存的 WindowsApps 路径也仍指向旧包。主题首帧虽然通过，窗口交接却被拒绝，后续图标绑定被跳过。

- 核对新版原生消息处理后加入支持；可见窗口不再触发多余的私有接口版本限制。
- 保留注册包、调试端口 Browser ID、进程和 HWND 匹配，未知版本的隐藏窗口不会盲目执行私有命令。
- 匹配真实主窗口后刷新客户端缓存路径，并恢复理世图标绑定。
- 开机自启改为安装器中的可选项，默认关闭；关闭时移除本项目登录项，遗留登录调用直接退出。手动桌面和任务栏启动仍播放展示动画。

修改前的 1.0.7 安装包、源码和本机安装状态已备份。Mac 保持 beta.4，本次为 Windows 专项修复。素材和上游项目引用见 THIRD_PARTY_NOTICES.md。

本机安装后验证（官方客户端 26.1016.8622.0）：桌面入口约 5.19 秒，任务栏快捷入口约 5.52 秒；隐藏主窗口后唤回约 6.45 秒，原会话保留。提前关闭动画后启动继续、等待时 Esc 退出、真实主窗口的理世图标绑定均通过。登录启动项和启用标记均不存在，直接执行遗留登录调用会正常退出，客户端进程保持不变。

上述为保留当前会话的入口与隐藏窗口测试，不代表已经完成整机重启或完全无后台冷启动实测。兼容测试还覆盖可见新版本窗口及未审查版本隐藏窗口的拒绝路径。
