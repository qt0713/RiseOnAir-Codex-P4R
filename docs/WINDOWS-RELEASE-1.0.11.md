Windows 1.0.11：适配官方 Codex 26.1120.6357.0。

新版将顶部栏改为 `data-app-shell-titlebar`，旧主题只识别旧顶部栏。失败日志中背景、主区域、样式均已就绪，唯一缺失项为 `header-tint`，导致启动校验持续等待、超时后撤回主题。

本次同时更新渲染器、验证器与样式的顶部栏规则，兼容新旧标记。新版顶部栏位于主区域外，使用透明背景并保留原生控件。没有删除或放宽主题就绪检查：主题 ID、版本、内容摘要、背景实际绘制、主区域和真实窗口仍须通过。

适配只修改受管理的 Dream Skin 副本；写入前校验三个上游文件的 SHA-256，保留原始字节备份，重复运行不叠加补丁，遇到外部修改拒绝覆盖。官方 WindowsApps 文件、登录资料和现有聊天进程保持不变。不开机自启。

本机验证：完整主题校验通过，桌面入口约 5.45 秒、任务栏快捷方式约 5.74 秒、隐藏窗口唤回约 6.67 秒；理世窗口图标、提前关闭动画后继续加载和 Esc 检查通过。以上是已有会话测试，不是电脑重启后的冷启动测速。

新增回归测试覆盖旧标记保留、新标记识别、重复应用、回滚、外部修改拒绝和写入前完整检查；就绪测试继续拒绝缺失背景、过期主题和不可见界面。GitHub Windows CI 执行这些测试，但不代替真实 Store 客户端验收。

后续更新若继续使用已支持的语义标记，可继续自动发现当前客户端并应用主题；重大结构变化仍需维护，不会下载执行未经校验的远程补丁。本次为 Windows 维护版，Mac beta.5 和 Android 原型未重新发布。
