macOS 1.1.0-beta.5：优化访达和 Dock 启动时的动画与主题加载。

- 由 WebKit 自行播放各图层，移除逐帧跳转和正式播放中的 PNG 截图编码。保留 3.2 秒展示版、日语问候、预览重播与 Esc。
- 播完即让出窗口，主题在后台继续验证；避免启动画面遮住正在等待验证的客户端。
- 完全冷启动跳过旧会话探测；已有会话的首帧探测使用只读快速签名校验。真正启动或重启应用仍执行完整签名验证。
- 同步进程号复用恢复和仅点击时启动。升级前请保存工作并退出官方客户端，再用新版替换 Applications 中的旧启动器。
- 提供 Universal DMG 和 ZIP。发布依赖 Apple Silicon 与 Intel 的原生测试。CI 不含已登录用户的真实客户端，动画播放结果不能代替用户机器的冷启动耗时。
